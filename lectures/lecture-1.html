Course overview

Game theory studies situations of conflict and cooperation in which two or more players interact. This course develops mathematical models of games and their applications in economics, business, politics, and evolutionary biology before moving on to mechanism design.

The course is organized around three broad areas:

  • Combinatorial game theory: Nim, Chomp, and related games.
  • Classical game theory: zero-sum games, general-sum games, evolutionary game theory, and correlated equilibria.
  • Mechanism design: cooperative games, social choice and voting, stable matching, and auctions.

Combinatorial games

The course begins with combinatorial games. Important distinctions include:

  • Randomness: Poker involves randomness; chess does not. The course focuses on games without randomness.
  • Information: Nim has complete information; Battleship has incomplete information.
  • Player symmetry: Nim is impartial, whereas Hex is partisan.

The main setting studied here consists of two-player games with no randomness and perfect information. Outcomes are wins or losses; draws are excluded. Under normal play, the last player to move wins, and play cannot continue indefinitely.

Definition of a combinatorial game

A combinatorial game is specified by:

  1. Two players.
  2. A set of possible positions.
  3. Rules specifying which moves are legal from one position to another.
  4. Whether the game is impartial or partisan. In an impartial game, the legal moves and winning positions are the same for both players; otherwise, the game is partisan.
  5. A terminal position: a position from which the player whose turn is next cannot move.
  6. A play convention:
    • Under normal play, the last player to move wins.
    • Under misère play, the last player to move loses.
  7. A finite ending condition: the game must end after finitely many moves, so there are no draws.

Progressively bounded games

Let \(X\) be the set of positions. A combinatorial game is progressively bounded if every starting position \(x\in X\) has a finite bound on the number of moves before the game terminates.

If \(B(x)\) denotes the maximum number of moves before the game ends when starting from \(x\), then

[ B(x)<xX. ]

Represent the game by a directed graph whose vertices are positions and whose directed edge \(x\to y\) represents a legal move from \(x\) to \(y\). In the setting considered here, the graph is finite and has no cycles.

A progressively bounded impartial combinatorial game (PBICG) has the same set of legal moves for both players, is played under normal play, and has no draws.

In-class games and examples

Nimble

Nimble is played on a strip with coins. A move consists of moving one coin to the left; a coin may also be moved off the strip. The last player to move a coin wins, so a player with no legal move loses.

One setup places one coin on the first square, two coins on the third square, and one coin on each square to the right of the third. A second setup places a coin on each of squares 1, 2, and 3. The strategic question is whether the two setups suggest a common winning method.

Nim

In the misère version used in the introduction, a player chooses a pile and removes any positive number of chips from it. The player who removes the last chip loses. Comparing Nimble with Nim motivates the search for strategies in combinatorial games.

The grade game

Each player chooses either \(\alpha\) or \(\beta\), and the choices are paired anonymously. The resulting grades are:

Your choice Partner chooses \(\alpha\) Partner chooses \(\beta\)
\(\alpha\) Both receive \(B-\) You receive \(A\); partner receives \(C\)
\(\beta\) You receive \(C\); partner receives \(A\) Both receive \(B+\)

This game illustrates that each player’s outcome depends on both players’ choices.

Subtraction game

The first subtraction-game example starts with a pile of \(n\) chips. The subtraction set is

[ S={1,2,3}. ]

Players take turns removing 1, 2, or 3 chips. The game is progressively bounded because the number of chips decreases on every move. To analyze it, work backward from the terminal position and classify positions according to which player can force a win.

N- and P-positions

Let \(N\) denote the set of positions from which the Next player can guarantee a win, assuming optimal play. Let \(P\) denote the set of positions where the next player cannot win, so the Previous player has a guaranteed win.

For the subtraction game with \(S=\{1,2,3\}\), the introductory exercise is to classify the positions when the initial pile has 10 chips, then use the results to conjecture a pattern.
